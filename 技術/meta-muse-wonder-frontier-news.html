Meta 首發前沿模型 Muse Wonder：主打長期記憶

2026年10月13日 10:00 • 閱讀時間 2 分鐘 • Eric Chan • 來源：TechCrunch

Meta 超級智慧實驗室（Superintelligence Lab）於十月十二日發布旗下首批前沿模型 Muse Wonder 與 Muse Wonder Full，官方在模型卡中表示兩者的基準測試成績已接近 GPT-6 Astra 與 Fable 5.1。這兩款模型透過 Meta Model API 提供，輸入定價為每百萬代幣四美元、輸出為二十美元，價位與 GPT-6 Sol 相當；其中 Muse Wonder Full 僅開放給 Muse Code 訂閱者，不對外提供 API。發布重點落在被官方稱為「主動記憶」的長期資訊保留能力，Meta 並以 MemoryBench 作為主要驗證指標，聲稱 Muse Wonder 的表現超越 Fable、Opus 與 Astra。這是 Meta 自去年八月重整人工智慧團隊後，首次推出定位為前沿等級的模型。

Muse Wonder 是什麼？

Muse Wonder 是 Meta 十月十二日發布的前沿模型，另有更大型的 Full 版本，兩者經 Meta Model API 提供，並用於驅動 Meta 自家的 Muse 代理。

Meta 將這次發布描述為模型規模階梯的下一步，並稱之為邁向個人超級智慧的重要進展。相較於先前主打低延遲、輕量定位的 Muse Spark，Wonder 系列屬於體積更大、能力更強的型號，在複雜任務與程式碼相關的測試中取得更好的結果。

兩款模型將同時用於驅動 Meta 的 Muse 代理，代表同一組底層能力會同時服務終端使用者與開發者介面。官方提到，訓練工作在位於俄亥俄州中部、今年啟用的 Prometheus 資料中心完成。Meta 過去一年陸續推出輕量模型與代理產品，但未發表與對手同級的前沿模型，這次發布補上了這塊缺口。

Muse Wonder 的效能與基準表現如何？

依 Meta 模型卡，Wonder 系列基準成績與 Fable 5.1、GPT-6 Astra 相當，在 MemoryBench 更超越上述對手（Meta 自測）。

官方強調的是綜合能力而非單一分數。根據 Meta 自行進行的測試，Wonder 系列在整體基準上已接近既有前沿模型，在程式碼等複雜任務的表現亦明顯優於前代產品。這類對比有助外界理解定位，但由於數據由開發方提供，第三方獨立評測的結果仍有待觀察。

較受關注的是記憶相關指標。Meta 指出 Wonder 在 MemoryBench 的得分高於 Fable、Opus 與 Astra，該基準專門測試持續學習與記憶建構框架的能力。研究人員 Kavya Kopparapu 在隨發布影片中表示，團隊投入大量心力，確保模型能記住對使用者重要的事情，時間跨度涵蓋數日、數週乃至數月以上。

Muse Wonder 的定價與可用範圍為何？

透過 Meta Model API，Wonder 輸入為每百萬代幣四美元、輸出二十美元，與 GPT-6 Sol 同級；較大的 Full 版本僅供 Muse Code 訂閱者使用。

價位落在一線模型的區間中央。四美元與二十美元的輸入輸出單價，意味 Meta 並非以低價搶市，而是直接把 Wonder 定位在與主流前沿模型正面競爭的位置，開發者在選型時需要以能力而非價格作為主要考量。

供應方式則帶有明顯的產品綁定設計。較大的 Muse Wonder Full 不透過 API 開放，只隨 Muse Code 訂閱提供，這種安排讓最高階能力留在自家產品生態內。對需要最大模型能力的團隊而言，取得途徑因此取決於是否採用 Meta 的訂閱方案，而非單純的 API 付費。

「主動記憶」對使用者意味什麼？

主動記憶指模型能長期保留並整合使用者提供的資訊，藉此改善跨時段的召回表現。這是 Meta 這次發布的核心賣點，目標是支撐可長時間執行任務的個人助理。

記憶能力的價值在於延續性。傳統對話模型每次互動的上下文有限，使用者往往需要重複說明背景；若模型能跨日、跨週保留關鍵資訊，助理才能承接長期任務，例如持續追蹤專案進度或累積個人偏好。

Meta 將這項能力與其發展個人助理的方向連結。公司長期表達對能長時間執行任務之助理的興趣，主動記憶正是支撐這種產品形態的技術前提。不過記憶越深，資料治理的考量也越重，資訊如何儲存、更新與刪除，將直接影響企業採用意願。

Meta 這次發布在競爭格局中代表什麼？

這是 Meta 團隊重整後首次推出前沿等級模型，象徵其從輕量模型與代理產品，重返與 OpenAI、Anthropic 正面競爭的層級，也讓前沿模型多一個主要供應者。

時間點具有指標意義。自 Scale AI 創辦人 Alexandr Wang 於去年八月重整 Meta 的人工智慧布局後，公司僅發布過輕量模型與代理產品，遲未推出與對手同級的前沿模型。Wonder 系列問世，代表 Meta 重新回到第一梯隊的競爭位置。

市場結構因此更趨集中。原本由少數幾家廠商主導的前沿模型市場，如今多了一個具備龐大資料中心與產品生態的參與者。對企業而言，選擇增加有助議價；對開發者而言，則需要重新評估不同模型在能力、成本與生態綁定上的取捨。

開發者與企業應如何看待這次發布？

開發者可先以 API 驗證 Wonder 在記憶與程式碼任務的實際表現，再決定是否納入生產流程；企業則應同時評估訂閱綁定帶來的鎖定風險與資料治理需求。

實務評估宜從可驗證的指標開始。官方基準數據僅供參考，團隊若考慮採用，建議先以自身任務集測試記憶保留與程式碼生成表現，再對照現行模型的成本與延遲，避免僅憑發布數字做出結論。

採購決策則需注意供應結構。最高階版本不經 API 提供，意味若產品需要該等級能力，就必須納入訂閱方案，長期成本與替換難度都要一併估算。此外，主動記憶涉及使用者資料的長期保存，企業在導入前宜先釐清資料存放位置、保留期限與合規條件。

常見問題有哪些？

常見疑問集中在模型是否開源、能否透過 API 使用，以及與既有模型的差異。官方目前僅提供 API 與訂閱兩種途徑，其中最大版本限定訂閱者使用。

Muse Wonder 是開源模型嗎？ 不是。Meta 目前僅透過 Meta Model API 與 Muse Code 訂閱提供，並未公布開源授權。

一般開發者可以使用嗎？ 可以。較小的 Muse Wonder 透過 Meta Model API 開放，按用量計費。

Muse Wonder Full 如何取得？ 該版本僅提供給 Muse Code 訂閱者，不經 API 提供。

與 GPT-6、Fable 相比如何？ 依 Meta 提供的基準數據，兩者表現相當，但尚待第三方獨立評測確認。

總結：Muse Wonder 適合什麼團隊？

Muse Wonder 適合需要長期記憶、且願意採用 Meta 生態的團隊；若需求集中在最高階能力，則須評估訂閱綁定帶來的成本與替換限制，並先以自有任務集實測。

Muse Wonder 象徵 Meta 重返前沿模型競賽，主打的主動記憶切中長時間任務的需求，定價則維持在一線區間。對開發者與企業而言，值得留意的並非單次發布的亮眼數字，而是記憶能力是否真能轉化為可用的產品體驗，以及訂閱綁定對長期架構的影響。在獨立評測出爐之前，先以小規模實測驗證，是較穩健的評估方式。
