OpenAI 推出 Admin 管理外掛 對話中直接管團隊

Eric Chan

IT 顧問・實測主義者

2026年08月26日 12:00 • 閱讀時間 2 分鐘

來源：9to5Mac

OpenAI 在 2026 年 8 月 25 日宣布推出 ChatGPT Work 與 Codex 的 Admin 外掛，讓工作區管理員直接在對話中完成成員管理、權限調整、用量分析與報表生成等日常工作。這項工具把管理員的例行事務搬進 AI 對話介面，大幅降低企業後台管理的操作門檻。

OpenAI Admin 外掛是 ChatGPT Work 與 Codex 的企業管理工具，管理員可在對話中直接管理成員、調整權限、分析用量與生成報表。外掛整合既有帳戶權限框架，支援自動化例行管理流程，並已在 ChatGPT Work 外掛目錄上架。

OpenAI Admin 外掛是什麼？

OpenAI Admin 外掛是專為 ChatGPT Work 與 Codex 工作區管理員設計的對話式管理工具。 OpenAI Admin 外掛是專為 ChatGPT Work 與 Codex 工作區管理員設計的對話式管理工具。管理員可以在對話中直接完成日常工作，包括檢視採用率與用量、管理成員與群組、調整存取權限、處理用量上限與請款要求，以及生成各種管理報表，全程不需要離開對話介面。

OpenAI 官方描述這項工具的定位是「讓管理員在 ChatGPT Work 與 Codex 中完成日常任務」，並強調三項核心能力：自動化重複性的管理流程、以既有控制項擴展管理規模、支援企業內部 IT 營運。換句話說，Admin 外掛不是取代現有管理後台，而是讓管理員多了一個自然語言的入口。

Admin 外掛可以完成哪些管理任務？

根據 OpenAI 公布的資料，Admin 外掛覆蓋四類管理任務。第一是採用與用量管理，管理員可以檢視 ChatGPT Work 與 Codex 的活動與額度使 根據 OpenAI 公布的資料，Admin 外掛覆蓋四類管理任務。第一是採用與用量管理，管理員可以檢視 ChatGPT Work 與 Codex 的活動與額度使用情況，找出需要加強導入的團隊，並掌握成員或群組何時接近額度上限。第二是成員與群組管理，包括新增或移除成員、更新群組，以及處理例行的入職、離職與團隊變動。

第三是存取權限管理，管理員可以檢視有效權限、診斷存取問題，並依角色或群組控制功能與模型存取範圍。第四是用量上限與請款管理，包括調整成員、群組與工作區的額度限制，檢視請款要求並依上下文核准或拒絕。這四大類任務過去需要逐一開設後台頁面操作，現在全部收進同一個對話流程。

Admin 外掛涵蓋四類任務：採用與用量分析、成員與群組管理、存取權限調整、用量上限與請款審批。管理員可在對話中完成從新增成員到核准請款的完整流程，不需要離開介面。

Admin 外掛在實際場景如何運作？

OpenAI 在示範中展示了 Admin 外掛的實際使用情境。一名準備進行每月 AI 導入檢討的管理員， OpenAI 在示範中展示了 Admin 外掛的實際使用情境。一名準備進行每月 AI 導入檢討的管理員，先詢問 ChatGPT Work 過去 30 天各團隊的採用率與額度使用變化，接著請求生成標示最大變化的圖表。整個過程中，管理員持續分析趨勢、要求更多細項與澄清、核准用量請求，最後由 ChatGPT 自動生成簡報並分享至 Slack 頻道。

這個示範清楚呈現了 Admin 外掛的設計邏輯：管理員的角色從「逐項操作系統」轉變為「下指令與決策」。報表生成、數據整理、簡報製作等耗時工作全部由 AI 代勞，管理員只需要確認方向與做最終決定，管理工作的效率因此大幅提升。

示範中，管理員以對話查詢 30 天採用率與用量變化，AI 生成圖表、分析趨勢、核准請款，最後自動製作簡報並分享至 Slack。整個流程從數據查詢到簡報輸出，都可以在對話中完成。

第三是 IT 營運整合，Admin 外掛支援內部 IT 作業流程，未來可望與更多企業工具串接。對企業而言，這代表 ChatGPT Work 從「團隊協作工具」進一步走向「企業管理平台」，AI 不再只是協助產出內容，而是直接參與組織的日常營運管理。目前 Admin 外掛已可在 ChatGPT Work 的外掛目錄中取得。
