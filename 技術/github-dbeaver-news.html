DBeaver 開源：5.2 萬星的資料庫工具

2026年10月15日 10:00 • 閱讀時間 4 分鐘 • Eric Chan • 來源：GitHub

內容創作者： https://github.com/dbeaver/dbeaver

DBeaver 是一套以 Java 撰寫的開源資料庫工具，在 GitHub 累積 52,058 顆星標與 4,407 次複製，採 Apache-2.0 授權。專案於 2015 年 10 月建立，2026 年 10 月 4 日發布 26.2.2 版本，重整 AI 引擎選擇介面，並修復自架 OpenAI 相容端點的模型探索問題。它同時提供桌面版、網頁版與命令列版本，社群版即可直接連線超過一百種資料庫，不必額外安裝驅動程式。

DBeaver 是什麼？

DBeaver 是一套跨平台開源資料庫管理工具，支援 SQL 編輯、資料瀏覽與 ER 圖，社群版內建超過一百種驅動，可連線幾乎所有具備 JDBC 或 ODBC 介面的資料庫。

它的定位是通用資料庫客戶端。開發者、SQL 程式設計師、資料庫管理員與分析人員可以在同一個介面裡連線不同引擎，不必為每一種資料庫分別安裝專屬工具。官方 README 列出的功能涵蓋結構編輯器、SQL 編輯器、資料編輯器、AI 對話、ER 圖、資料匯入匯出與遷移、執行計畫、資料庫管理工具、儀表板、空間資料檢視器、代理與 SSH 通道，以及自訂驅動編輯器。

跨引擎能力來自驅動抽象層。社群版出廠即支援超過一百種驅動，範圍從關聯式資料庫如 PostgreSQL、MySQL、Oracle、SQL Server，延伸到分析型引擎如 Snowflake、Databricks、ClickHouse 與 Trino，也包含檔案型來源如 CSV、Parquet、XLSX 與 JSON。任何提供 JDBC 或 ODBC 介面的引擎，都能透過自訂驅動設定接入。

專案本身的技術選擇偏向成熟生態。DBeaver 以 Java 為主要語言，桌面介面建構在 Eclipse RCP 之上，並保留一組原生系統元件處理介面、高效能驅動與網路連線。這種組合讓它能在 Windows、macOS 與 Linux 上維持一致的操作體驗。

26.2.2 版本更新了哪些內容？

26.2.2 版於 2026 年 10 月 4 日發布，重點是 AI 引擎選擇介面改用原生下拉選單，並修復自架 OpenAI 相容端點的模型探索，另含多項介面與資料庫支援修正。

AI 助理是這次更新的主軸。官方版本說明指出，AI 引擎選擇器改用原生下拉選單，加入引擎圖示並改善鍵盤操作；針對自架 OpenAI 相容端點，修復了非 OpenAI 命名模型的探索問題，也修正在基礎網址缺少結尾斜線時的模型列表與對話請求。當自訂 AI 範圍內沒有資料庫物件時，驗證與提示訊息同樣獲得改善。macOS 上開啟 AI 設定檔或模型選擇器時會立即選取項目的問題，也在本次修復。

SQL 編輯器新增一項實用設定，讓使用者自行決定以 Enter、Tab、兩者或皆不接受的按鍵確認自動完成建議；另可關閉大型指令碼的結果抓取警告。資料編輯器修復日曆元件遇到不支援的日期時間值時，問題回報連結無法點擊的情況，並統一虛擬結構編輯器的間距與背景。

連線精靈與資料庫支援亦有調整。當所選資料庫存在多個連接器選項時，精靈會提示使用者先做選擇；Apache Doris 的 CSV 匯入與匯入後資料表更新獲得修復；PostgreSQL 新增在權限頁面檢視與管理 PUBLIC 虛擬角色的支援；Timeplus 修正 CSV 匯入的數值錯誤與間歇性停頓。版本同時改善暫存檔堆積與清理、版本更新控制的重複下載問題，以及偏好設定的搜尋關鍵字。

DBeaver 的技術架構如何組成？

架構以 OSGi 外掛平台與 Eclipse RCP 介面框架為主，搭配 JDBC 連線與 Antlr4 解析 SQL 語法，並區分模型與介面外掛，讓後端元件可同時重用。

外掛化是整體設計的核心。社群版由 130 個以上外掛組成，透過 OSGi 平台管理相依與載入；介面層則建立在 Eclipse RCP 之上，這也是它能維持桌面級操作手感的原因。SQL 語法處理交由 JSQLParser 與 Antlr4 負責解析。

分層方式決定了產品線的延伸能力。官方把模型外掛與介面外掛分離，同一組後端元件既能供 DBeaver 桌面版使用，也能供 CloudBeaver 網頁版使用，因此兩者在連線能力上具備一致性，差異集中在操作介面。第三方相依透過 P2 儲存庫管理，Maven 相依則由官方自建的儲存庫提供。

原生元件補足了 Java 的限制。官方說明指出，DBeaver 使用一組作業系統專屬的原生元件處理桌面介面、高效能資料庫驅動與網路功能，另外導入多個開源函式庫，包含 SSH 連線的 SSHJ、Office 檔案處理的 Apache POI、圖表繪製的 JFreeChart，以及幾何運算的 JTS。這些選擇解釋了為何工具能同時支援 SSH 通道、空間資料檢視與檔案型資料來源。

免費社群版與 PRO 版有什麼差別？

差別主要在資料庫範圍與 AI 供應商：社群版免費並內建一百多種關聯式驅動與 AI Chat，商業版解鎖 NoSQL 驅動與更多原生 AI 供應商，並附線上支援。

社群版已經覆蓋多數日常需求。它出廠支援一百多種驅動，包含主流的關聯式與分析型資料庫，並附帶 AI Chat 介面、ER 圖、資料匯入匯出與 SSH 通道，授權為 Apache-2.0，可自由用於商業環境。

商業版本補上的是邊界場景。官方列出 PRO 版與其他商業版本額外支援的引擎，包含 MongoDB、Cassandra、Couchbase、DynamoDB、Redis、Neo4j、InfluxDB 與 BigTable 等 NoSQL 與時序資料庫，另支援以 Apache Calcite 為基礎的聯邦查詢，可同時查詢多個來源。檔案型來源如 Parquet、XLSX 與 XML 的支援也在商業版本範圍內。

AI 供應商的分界同樣明顯。社群版的 AI Chat 提供 OpenAI 與 Copilot 兩條路徑，其中 OpenAI 選項允許設定自訂端點，因此可指向多數相容服務；商業版本則原生支援 Anthropic、Grok、Azure、Bedrock、Gemini 與 Ollama 等供應商，並附帶額外的 AI 工具。授權使用者另享有問題修復與新功能的優先處理權。

DBeaver 支援多少種資料庫？

社群版支援超過一百種驅動，涵蓋 PostgreSQL、MySQL、Oracle、SQL Server 等主流資料庫；具備 JDBC 或 ODBC 介面的引擎可自訂驅動接入。

支援清單以驅動數量計算。官方 README 逐一列出社群版內建驅動，範圍從 Apache Doris、ClickHouse、CockroachDB、DuckDB、Elasticsearch，到 Google BigQuery、Snowflake、SQLite、Teradata、TiDB 與 Yugabyte，長度超過一百項。這意味著多數企業環境中既有的資料庫，都能在不安裝額外套件的情況下直接連線。

自訂驅動能力補上清單之外的部分。由於核心走 JDBC 與 ODBC 標準，任何提供這類介面的引擎都能透過驅動編輯器加入，包含內部自建系統或較冷門的商業資料庫。這個設計讓 DBeaver 的實際支援範圍取決於是否存在對應驅動，而非官方是否預先收錄。

檔案與非資料庫來源也在支援範圍內。社群版可把 CSV、DBF 等檔案當作資料表查詢，商業版本進一步納入 Parquet、XLSX、JSON 與 XML，並提供以 Apache Calcite 為基礎的聯邦查詢層，讓跨來源的聯合查詢不必先做資料搬移。

AI 功能在 DBeaver 中如何運作？

AI Chat 以對話形式生成、分析與最佳化 SQL，並自動帶入資料庫結構與 SQL 方言等脈絡；社群版支援 OpenAI 相容端點與 Copilot，其餘供應商需商業版本。

整合方式偏向情境感知。官方說明指出，所有 DBeaver 產品都內建類似一般 LLM 對話的 AI Chat 檢視，可用於生成、分析與最佳化 SQL 查詢、操作資料庫結構，甚至在不熟悉 SQL 的情況下操作資料。系統會把資料庫結構與 SQL 方言等資訊一併提供給模型，讓產出的語句更貼近實際環境。

成本控制是設計重點之一。官方強調這套整合使用依情境變動的動態工具，在 token 消耗上相對有效率，避免每次請求都夾帶完整結構描述。對於資料量龐大或結構複雜的環境，這項設計直接影響長期使用成本。

供應商選擇依版本而異。社群版的 OpenAI 選項允許設定自訂端點，因此可指向任何相容的服務，包含本機推論服務；Copilot 則提供另一條路徑。若需要原生支援 Anthropic、Gemini、Azure、Bedrock、Grok 或 Ollama，以及額外的 AI 工具，則屬於商業版本範圍。

如何安裝與開始使用 DBeaver？

安裝方式為下載官方安裝檔或壓縮檔，執行安裝後啟動即可使用；發行版已內含 OpenJDK 25，不需另外準備 Java 環境，社群版與企業版皆為免費下載。

桌面版提供安裝檔與壓縮檔兩種形式。官方網站與 GitHub Releases 都提供預先建置的執行檔，另有一條每日更新的早期存取版本通道。安裝程式執行完成後點擊應用程式圖示即可啟動；偏好可攜式使用的環境，解壓縮後直接執行命令列啟動程式亦可。

Java 環境已隨發行版提供。官方說明指出，執行 DBeaver 需要 Java，而所有發行版都內含 OpenJDK 25，因此不需另行安裝執行環境；若有特定版本需求，可替換安裝目錄下的 Java 目錄。這個做法降低了企業環境的部署門檻。

延伸產品覆蓋不同使用場景。同一個團隊另外維護 CloudBeaver，以網頁形式提供資料庫管理介面，可透過 Docker 部署，累積 5,195 顆星標；另有命令列工具 dbvr，適合放進 CI/CD 流程與自動化腳本。三者共用同一組後端外掛，因此連線能力保持一致。

DBeaver 的專案維護現況如何？

專案自 2015 年建立至今提交超過兩萬九千次，貢獻者達 367 人；發行節奏約每兩週一個版本，2026 年內已推出多個版本，並同時維護網頁版與命令列版本。

發行節奏相當固定。官方版本紀錄顯示，專案約每兩週發布一次更新，2026 年 7 月至 10 月之間已推出 26.1.3 至 26.2.2 共六個版本，主題涵蓋功能新增、介面調整與各資料庫支援修正，最新版本於 10 月 4 日發布，附帶 12 個可下載檔案。

社群規模與維護負擔同時反映在數字上。專案累積超過兩萬九千次提交與 367 位貢獻者，未結議題約 3,300 個。官方 README 說明，團隊正主動尋找新的程式碼貢獻者，並在部分議題標記「適合新手」與「徵求協助」標籤；社群亦可透過點讚提升特定議題的優先順序。

治理與商業模式並行。專案採 Apache-2.0 授權釋出原始碼，同時經營商業版本與線上支援服務，並以獎勵方式回饋每輪活躍貢獻者。這種模式讓社群版保持完整功能，商業收入則支撐持續開發。

DBeaver 常見問題有哪些？

以下整理 DBeaver 是否需要付費、能否離線使用 AI 功能，以及企業環境部署時應留意的授權與安全考量等常見疑問。

DBeaver 需要付費才能使用嗎？

社群版免費且開源，採 Apache-2.0 授權，可自由用於商業環境，功能涵蓋一百多種資料庫驅動與 AI Chat。付費版本針對 NoSQL 資料庫、更多 AI 供應商與官方線上支援，屬於需求導向的加值選項，而非使用前提。

AI 功能可以完全在本機執行嗎？

可以，但有版本限制。社群版的 OpenAI 選項允許設定自訂端點，因此能指向本機推論服務；若需要原生支援 Ollama 供應商與額外 AI 工具，則屬於商業版本範圍。無論哪種路徑，模型推論是否離開本機，取決於所選端點。

企業環境部署時要注意什麼？

授權與版本選擇是主要考量。社群版以 Apache-2.0 釋出，可用於內部系統與商業用途；若需要 NoSQL 支援或官方支援服務，則需評估商業授權。另外由於工具會連線資料庫並可整合外部模型，連線憑證與 AI 端點的設定應納入既有的存取控管流程。

總結：DBeaver 適合哪些使用者？

適合需要同時連線多種資料庫、重視桌面操作效率或對資料落地位置有要求的開發者與資料庫管理員；若工作重心是雲端託管的協作介面，網頁版會更合適。

DBeaver 的價值在於把資料庫存取的介面層統一起來。同一套工具能連線超過一百種引擎，社群版以 Apache-2.0 授權提供完整核心功能，讓團隊不必為每一種資料庫採購不同的客戶端。52,058 顆星標與 367 位貢獻者反映的，正是這種通用性在企業環境中的實際需求。

它的取捨同樣清楚。外掛化架構帶來廣泛支援，也讓安裝體積與啟動負擔高於輕量客戶端；NoSQL 與部分檔案格式屬於商業版本範圍，需要額外評估。對於需要在異質環境中快速切換資料庫、或希望把查詢操作留在自己機器上的使用者，這仍是目前開源選項中最完整的組合之一。
