微軟開源 24 堂前端入門課：96,919 星

Eric Chan

IT 顧問・實測主義者

2026年10月08日 20:00 • 閱讀時間 2 分鐘

來源：GitHub

內容創作者： https://github.com/microsoft/Web-Dev-For-Beginners

微軟開源的 Web Development for Beginners 課程儲存庫在 GitHub 累積 96,919 顆星標與 16,011 次複製，是前端入門領域規模最大的免費教材之一。這套課程以十二週、二十四堂課為架構，透過專案式教學帶領學習者掌握 HTML、CSS 與 JavaScript，並藉由 GitHub Action 自動同步五十多種語言的社群翻譯。

微軟開源的 Web-Dev-For-Beginners 是一套十二週、二十四堂課的前端入門教材，以專案式教學教授 HTML、CSS 與 JavaScript。

Web-Dev-For-Beginners 是什麼？

Web-Dev-For-Beginners 是微軟雲端倡導者團隊維護的開源前端課程，涵蓋 HTML、CSS 與 JavaScript，全部教材以 MIT 授權釋出。

依照官方說明，這套課程的目標是讓初學者在十二週內建立前端開發的基礎。課程由微軟雲端倡導者團隊編寫，原始碼與教材全部公開，任何人可自由複製、修改與再用。課程以 MIT 授權釋出，主要語言為 JavaScript，同時包含大量 HTML、CSS、Vue 與 Python 範例。

儲存庫建立於二零二零年十一月，至今累積 16,011 次複製與 2,669 位關注者，程式碼仍在持續更新。授課語言以英文為主，但透過自動化翻譯流程，教材已覆蓋五十多種語言版本，其中包括繁體中文的香港、澳門與台灣三種地區版本。

這門課程包含哪些內容與結構？

課程分為二十四堂，涵蓋程式語言入門、JavaScript 基礎、HTML 與 CSS 實作、瀏覽器擴充功能、遊戲開發與銀行應用，每堂皆有測驗、作業與挑戰題。

課程的內容安排由淺入深。前段介紹程式語言與開發工具的基礎，接著進入 JavaScript 的資料型別、函式、條件判斷、陣列與迴圈。中段轉向實作，學習者要親手完成一個線上生態箱，從 HTML 版面、CSS 樣式到以 JavaScript 實作拖放互動，逐步理解閉包與文件物件模型的操作。

後段難度持續提升。學習者會製作打字遊戲以理解事件驅動程式設計，開發環保主題的瀏覽器擴充功能並學會呼叫應用程式介面與使用本機儲存，再以太空遊戲練習類別、組合與發布訂閱模式，並學到畫布繪圖、元素移動、碰撞偵測與計分邏輯。最後以一個銀行應用收尾，涵蓋路由、範本、表單驗證、資料處理與狀態管理。課程亦包含以視覺化程式碼編輯器與人工智慧助理為主題的延伸單元。

每堂課的結構一致，包含預習測驗、課堂講解、知識檢查、挑戰題、延伸閱讀與課後作業。全部四十八組測驗可透過課程附帶的測驗應用在本機執行，或部署到雲端服務使用。

多語言翻譯與社群如何運作？

課程透過 GitHub Action 與自動翻譯工具同步五十多種語言版本，社群可提交修正與新翻譯，官方另設討論區與行為準則維持協作品質。

多語言支援是這套課程最特殊之處。專案採用社群協作翻譯機制，由 GitHub Action 在原始教材更新後自動同步各語言版本，確保譯文不會落後於英文原文。目前支援的語言涵蓋亞洲、歐洲與中東地區，繁體中文部分更細分為香港、澳門與台灣三種地區版本，對華語學習者相對友善。

社群參與的門檻不高。學習者若發現譯文錯誤或教材過時，可依貢獻指南提交修正，專案並設有討論區供教師與學習者交流使用經驗。官方亦提供行為準則與教師使用建議，讓學校或培訓機構能直接把課程當作正規教材使用。儲存庫的貢獻者數量超過兩千人，是課程能長期維持內容品質的主要原因。

它與其他入門課程有何不同？

此課程以專案帶動學習、以頻繁測驗鞏固記憶，並刻意避開前端框架，先建立原生 HTML、CSS 與 JavaScript 的基礎能力。

課程採用兩項教學原則，一是專案式學習，二是頻繁測驗。學習者不是先讀完語法再找題目練習，而是直接進入打字遊戲、生態箱、太空遊戲等專案，在解決問題的過程中理解語法與設計模式。每堂課前後各有一組測驗，前者引導學習方向，後者檢驗理解程度。

另一項差異是課程刻意不引入前端框架。官方說明指出，先打好原生 HTML、CSS 與 JavaScript 的基礎，再學習框架會更順利，因此課程把框架相關內容留給後續資源。這種安排對想理解瀏覽器運作原理的學習者較有幫助，但對於急需投入框架專案的人，仍需要搭配其他教材。

課程亦具備離線使用能力。學習者可複製儲存庫後以文件生成工具在本機架設網站，或直接下載由官方產出的課程合併檔案，在沒有網路的情況下閱讀。

開發者如何開始使用這套課程？

使用者可先複製儲存庫，再於瀏覽器版的雲端開發環境或本機的程式碼編輯器開啟，依課程目錄逐堂完成測驗、教材與作業。

開始使用的方式有兩種。若不想安裝任何軟體，可在複製儲存庫後，直接以雲端開發環境開啟，瀏覽器便會建立一個可直接編輯與執行的專案空間，第一堂課會說明各種工具選項與取捨。若偏好本機作業，則需準備程式碼編輯器、瀏覽器與命令列工具。

本機環境的建議配置為程式碼編輯器加上即時預覽與人工智慧輔助外掛。學習者把儲存庫複製到本機後，以編輯器開啟資料夾，即可依課程目錄逐堂進行。官方建議搭配每堂課的預習與課後測驗，並在討論區與其他學習者共同完成專案，以提升學習效果。

這套課程的市場定位與教育影響如何？

此課程屬微軟開發者教育系列的一環，與人工智慧、機器學習等入門課程並列，以低門檻、可自學與可再用為主要定位。

這套課程並非獨立專案，而是微軟開發者教育系列的一部分。同一系列還包含機器學習、人工智慧、資料科學、物聯網與資安等入門課程，皆採相同的教材結構與授權方式，形成一套可互相銜接的學習路徑。這種布局讓初學者可依興趣延伸，也讓教育機構能以較低成本建立課程。

在市場定位上，課程的價值不在於取代付費訓練，而在於降低起步門檻。九萬六千顆星標與兩千多位貢獻者的規模，代表它在自學者社群中已具備一定的信任度；對企業而言，這類公開教材也常被用於內部培訓的基礎材料。需要留意的是，課程以英文原文維護，譯文雖由自動流程同步，深度教學仍建議搭配官方文件與實作練習。

常見問題有哪些？

常見疑問集中在課程是否免費、需要多少前置知識、是否適合教師使用，以及翻譯品質；官方教材皆可免費取用，建議具備基本電腦操作能力即可開始。

這套課程需要付費嗎？

不需要。課程以 MIT 授權釋出，教材、程式碼與測驗皆可免費使用，也可用於商業與教學用途。

完全沒有程式基礎可以學嗎？

可以。課程從程式語言與工具的基本概念開始，第一堂課會說明各種開發工具的差異，協助初學者選擇環境。

需要安裝哪些軟體？

若使用雲端開發環境則無需安裝。本機學習建議準備程式碼編輯器、瀏覽器與命令列工具，官方推薦使用 Visual Studio Code。

繁體中文版是否完整？

專案提供香港、澳門與台灣三種繁體中文版本，並由自動流程同步更新。深度技術細節仍建議對照英文原文。

教師可以直接把課程當教材嗎？

可以。專案附有教師使用建議與行為準則，學校與培訓機構可直接採用，或依需要挑選部分單元。

課程有涵蓋前端框架嗎？

沒有。課程刻意專注原生 HTML、CSS 與 JavaScript，官方建議先建立基礎，再以其他資源學習框架。

沒有網路時可以使用嗎？

可以。學習者可複製儲存庫後以文件生成工具在本機架設網站，或下載官方產出的合併檔案離線閱讀。

如何回報教材錯誤？

可透過儲存庫的議題頁面或提交修正請求回報，專案並設有討論區供學習者與維護者交流。

總結：Web-Dev-For-Beginners 適合哪些學習者？

這套課程適合想打好原生前端基礎的自學者、需要現成教材的教師，以及規劃內部培訓的企業；若目標是直接上手框架，仍需搭配其他資源。

Web-Dev-For-Beginners 的價值在於把一套結構完整、可自學、可再用，而且長期有人維護的前端教材公開釋出。九萬六千顆星標與兩千多位貢獻者代表的不只是關注度，更是一套能持續修正與翻譯的教學基礎設施。對初學者而言，十二週、二十四堂課的節奏明確，專案與測驗交替能有效檢驗學習成果；對教師與企業而言，MIT 授權與多語言版本大幅降低了備課成本。若學習目標是盡快投入特定框架專案，這套課程適合作為基礎訓練，而非唯一來源。
