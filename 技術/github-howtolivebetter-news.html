6.4 萬星人生指南：765 條建議附證據

2026年10月17日 10:00 • 閱讀時間 2 分鐘 • Eric Chan • 來源：GitHub

內容創作者： https://github.com/eternity4719/HowToLiveBetter

HowToLiveBetter 是一份以證據為基礎的中文開源生活指南，於 2026 年 9 月在 GitHub 發布，把可延長壽命、節省時間與金錢、降低法律風險的建議，整理成 34 節、共 765 條條目。每條條目都標明需要付出什麼成本、能換回什麼收益、證據等級有多高，並且只引用期刊論文與官方文件。截至 2026 年 10 月中，專案累積約 6.4 萬顆星標與 5.4 千次複製，同時提供線上檢索頁、PDF、EPUB 與 Anki 牌組等多種取用形式。

HowToLiveBetter 是什麼？

它是一份以期刊論文與官方文件為來源的中文生活決策指南，2026 年 9 月在 GitHub 開源，涵蓋 34 個章節、765 條建議，每條都標示成本、收益與證據等級。

專案由開發者 eternity4719 於 2026 年 9 月 7 日建立，定位是一份「備選單」而非任務清單，作者在說明中坦言自己也沒有做到其中大部分條目。內容分成 34 節，涵蓋不要早死、不要慢慢死、不要浪費精力、不要浪費錢、普通人的法律紅線、租房與買房、慢性病照護、退休與遺產安排等主題，並以 CC BY 4.0 授權釋出。

每一節的標題描述的是一組想防住的結果，例如「不要浪費時間」對應的是把時間用在有回報的事情上，並非要求讀者停止一切娛樂。條目標題一律以動詞開頭，讀者可以從標題直接判斷該條屬於「做什麼」還是「別做什麼」。

765 條建議如何標示成本與證據等級？

每條建議固定列出成本、說人話、收益、證據等級、來源與備註六個欄位；證據等級分 A、B、C 三檔，其中 A 級共 495 條，取自薈萃分析或大型隨機試驗。

成本欄說明需要付出的金錢、時間、精力與毅力，「說人話」欄則把研究中的統計寫法翻譯成日常描述，例如把風險比轉述為「同期死亡的概率低約兩成」。收益欄保留全部原始數字，包括樣本數量、追蹤年數與風險比，讓讀者可以自行核對。

證據等級依來源的方法學強度分級，A 級對應有具體數字、來自薈萃分析或大型試驗的條目，共 495 條；B 級 218 條、C 級 52 條。備註欄則記錄爭議與適用範圍，例如低鈉鹽一條會提醒腎功能不全或正在服用保鉀類藥物的人，更換前應先諮詢醫生。

專案另設四個收益維度，包括壽命、時間與精力、金錢與人身自由，並按「好處有多大機率回到自己身上」區分自己、直系親屬、朋友同事與陌生人的四種檔次，不同檔次不合併計算。

專案提供哪些閱讀與檢索方式？

專案提供線上檢索頁、單一檔案離線 HTML、A4 排版 PDF、EPUB 電子書與 Anki 牌組五種形式，全部由正文自動重新生成，下載連結固定不變。

線上檢索頁可按關鍵字、章節與證據等級篩選，也可以依「花不花錢、花多少時間、需不需要毅力」三個條件疊加篩選。條目之間的相互指引在檢索頁中顯示為虛線，點擊後就地展開被指向條目的標題與說明，不必離開頁面。

單一檔案離線版把整本書、檢索與篩選功能收在一個 HTML 檔案內，雙擊即可開啟，不需要伺服器或網路連線。PDF 採 A4 排版、兩百多頁，附目錄頁碼與書籤；EPUB 可透過 Send to Kindle 傳送至閱讀器；Anki 牌組則以一條建議一張卡片的形式匯入，正面為建議、背面為說明、成本與證據等級。

若不採用線上版本，也可以在本地端執行 git clone 後以 Python 內建的靜態伺服器開啟，專案不需要後端、資料庫或額外套件，把整個目錄交給任何靜態伺服器即可運作。

如何用 AI 助手查詢書中條目？

儲存庫附帶名為 life-decision-guide 的中文 skill，可安裝於 Claude Code 與 Codex；提問時先檢索書中條目，再標明出自第幾條。

安裝該 skill 之後，使用者可以直接提出具體問題，例如是否應該為朋友作擔保、每天通勤兩小時是否值得。助手會先從正文中查出相關條目，再依書中的成本與收益算法排序回答，同時標示引用的節次與條號。

設計上要求助手查不到時如實說明，不得自行編造數字。這種做法把生成式模型的回答限制在既有條目範圍內，讓輸出的內容可以被讀者回溯至原始文獻，降低憑印象作答的風險。

為什麼它能在短時間內累積 6.4 萬顆星標？

專案把成本與收益寫成可查證的帳目，來源一律指向原始文獻，填補了生活決策缺乏依據的空白；加上純靜態、無後端的架構，使傳播與自行部署的成本極低。

專案在 2026 年 9 月上旬建立，一個多月內即取得約 6.4 萬顆星標與 5.4 千次複製，並衍生出多語翻譯與社群維護的版本。成長動能來自可驗證性：多數生活建議僅提供結論，而此專案同時公開樣本規模、追蹤時間與風險比，讓讀者能判斷結論的適用邊界。

技術層面同樣降低了門檻。專案沒有伺服器端邏輯，正文即資料，任何靜態託管服務都能承載；離線單頁版本更讓內容可以在通訊軟體中直接轉發，不必依賴特定平台。

使用時需要注意哪些限制？

作者表明內容可能過時或出錯，各地執行標準不一；法律、醫保與社保條目以中國大陸現行規定為準，實際辦事與就醫時應以當地部門、醫生與律師的說法為依據。

這是全書最重要的前提。政策與法規在不同地區的執行方式常有差異，醫療處置更需要考量個人病史與用藥狀況，因此書中條目適合視為決策前的準備清單，而非最終依據。

此外，專案明確聲明未曾發行任何代幣或數位資產，並提醒以專案名義發行的加密資產均與作者無關。讀者在搜尋相關資源時，應以官方儲存庫與線上檢索頁為準，避免循第三方連結下載來源不明的檔案。

總結：這份指南適合哪些讀者？

適合希望以低成本改善壽命、時間、金錢與人身自由的讀者，也適合需要為決策尋找可查證依據的人；若涉及具約束力的法律或醫療判斷，仍應諮詢專業人士。

這份指南的價值在於把模糊的生活建議轉換成可核對的條目，讀者可以依證據等級或性價比篩選，先處理最有把握的幾件事，而不必一次消化全部內容。四位一體的收益框架，也讓「值得做」有了可比較的尺度。

採用時應留意兩項邊界：書中內容以中國大陸現行制度為基準，其他地區讀者需要對照本地規定；作者亦已說明條目可能過時或存在錯誤。把它當作查證的起點，而不是終點，才能發揮它在決策前的整理作用。
