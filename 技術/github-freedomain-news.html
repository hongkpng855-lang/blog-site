FreeDomain 開源：20 萬星的免費域名平台

Eric Chan

IT 顧問・實測主義者

2026年10月05日 22:00 • 閱讀時間 3 分鐘

來源：GitHub

內容創作者： https://github.com/DigitalPlatDev/FreeDomain

FreeDomain 是一套由 DigitalPlat 基金會維護的免費域名註冊專案，在 GitHub 累積 202,637 顆星標與 4,445 次複製，提供五種免費域名後綴，並附帶一本從域名基礎到網站部署的完整教學手冊。截至二零二六年十月，平台已發出逾五十萬個域名，成為開源社群中規模最大的免費域名計畫之一。

FreeDomain 是 DigitalPlat 基金會維護的免費域名註冊專案，提供 .US.KG、.QZZ.IO 等五種後綴，平台已發出逾五十萬個域名。

FreeDomain 是什麼？

FreeDomain 是開源免費域名註冊服務，使用者註冊後可取得一個域名，再自行指定外部權威名稱伺服器來管理解析，專案本身不提供 DNS 記錄編輯。

FreeDomain 的定位並非傳統域名註冊商，而是一個降低上線門檻的社群計畫。它讓使用者免費取得一個可用的域名，但把解析工作交給外部的權威名稱伺服器供應商，自身只負責域名的核發與委派。專案由 DigitalPlat 基金會維護，應用程式原始碼則公開於另一個儲存庫，以 AGPL-3.0 授權釋出。

這個設計帶來一個關鍵差異。多數免費域名服務會連帶提供一個簡易的 DNS 記錄後台，讓使用者直接新增 A、CNAME 等紀錄；FreeDomain 則刻意不做這一層，改為要求使用者自行選擇 Cloudflare 或其他支援權威名稱伺服器的供應商。專案在文件中反覆強調，所有關於 A、AAAA、CNAME、MX 與 TXT 的教學，都屬於外部 DNS 供應商的範疇，而非 FreeDomain 本身的功能。

FreeDomain 為什麼能累積 20 萬顆星標？

計畫源自創辦人十五歲時的 DNS 實驗，從讓朋友使用子域名開始，逐步成長為服務逾五十萬名使用者的平台，並因免費與教學完整而廣受關注。

專案的成長軌跡帶有明顯的社群色彩。創辦人 Edward Hsing 在專案文件中說明，這項計畫最初只是他十五歲時的一個小型 DNS 實驗，用來讓幾位朋友使用子域名；隨著使用人數增加，營運的難度反而超過開發本身，最終演變為服務數十萬名使用者的平台。

免費與教育並行的策略，是星標快速累積的主因。專案除了提供域名，還把整個學習路徑寫成一本書，涵蓋網際網路基礎、DNS 記錄、網站建置、HTTPS、電子郵件與營運維運等主題，讓不曾接觸過域名的新手能在同一個地方完成從註冊到部署的流程。這種「工具加教材」的組合，讓它在教學社群與學生族群之間持續擴散。

FreeDomain 提供哪些域名後綴與使用限制？

目前提供 .DPDNS.ORG、.US.KG、.QZZ.IO、.XX.KG 與 .QD.JE 五種後綴，每個帳號預設限註冊一個域名，但可在該域名下自行建立子域名。

可選的後綴包括 .DPDNS.ORG、.US.KG、.QZZ.IO、.XX.KG 與 .QD.JE，專案表示未來會陸續增加。每個使用者帳號預設只能註冊一個域名，官方說明這項限制是因應域名濫用增加而設，目的是維持平台資源的公平分配；若需要更多名稱，仍可在已取得的域名之下建立子域名，例如在 example.foo.us.kg 的架構下自行延伸。

除了數量限制，專案亦設有濫用檢舉機制。使用者若發現域名被用於不當用途，可透過電子郵件向基金會檢舉，官方會逐案審查。此外，專案在公告中特別提醒，其先前的 Telegram 帳號與群組已遭入侵且不再受控，因此任何來自 Telegram 的公告、連結或收益訊息都不應採信，官方已不再使用 Telegram 作為溝通管道。

FreeDomain 如何註冊與設定域名？

先在官方控制台註冊帳號並申請域名，再把取得的域名委派給支援權威名稱伺服器的外部 DNS 供應商，之後所有解析紀錄都在該供應商設定。

註冊流程分為兩個階段。使用者先前往官方控制台建立帳號，提出域名申請，取得一個可用的名稱；接著在控制台填入由外部 DNS 供應商提供的權威名稱伺服器紀錄，完成委派。此後所有 A、AAAA、CNAME、MX 與 TXT 等解析設定，都在該供應商的管理介面完成，FreeDomain 端不再介入。

專案也鼓勵進階使用者自行架設 DNS 基礎設施。官方文件指出，使用者可以選擇任何提供權威名稱伺服器的服務，亦可自行維運；但基金會明確表示不背書或保證任何第三方供應商，使用者須自行評估其功能、安全性、可用性、條款與價格。這種把責任界線劃清的作法，讓平台得以在免費的前提下維持運作。

FreeDomain 的 DNS 教學資源包含什麼？

教學手冊分為產品指南與通用教材兩大部分，涵蓋帳號註冊、名稱伺服器委派、DNS 記錄類型、網站部署、HTTPS、電子郵件與維運等主題。

專案的教學內容以書籍形式組織，明確區分為兩類。第一類是 FreeDomain 產品指南，說明帳號註冊、域名申請、外部名稱伺服器連接、狀態與續期、帳號政策以及 API 的安全使用方式；第二類是通用的域名與網站教科書，從網際網路如何傳輸資料、終端機與檔案基礎談起，一路延伸到 DNS 記錄類型、TTL 與快取、故障排除、靜態網站建置、伺服器準備、HTTPS 啟用、電子郵件紀錄與效能調校。

這種分層寫法解決了免費域名服務常見的痛點。使用者往往在拿到域名後，才發現自己不清楚 DNS 的運作方式，於是在各種教學頁面之間跳轉；FreeDomain 把這些知識集中在同一個儲存庫，並以相對連結串接，讓讀者能依照順序學習。專案亦開放文件貢獻，歡迎社群修正錯誤、補充範例與改善說明。

FreeDomain 與付費域名註冊商有何差異？

差異在於成本、名稱選擇與控制權。FreeDomain 免費但僅限特定後綴且每帳號一個域名；付費註冊商收年費，可選主流後綴並附帶 DNS 後台與技術支援。

兩者的取捨集中在三個面向。第一是成本，FreeDomain 不收費用，適合個人專案、學生作業與實驗性質的網站；付費註冊商則按年收費，但通常包含 DNS 管理後台與客戶支援。第二是名稱選擇，FreeDomain 僅提供五種後綴，辨識度與通用性不及 .com、.org 等主流後綴，對於需要建立品牌信任的商業網站並不理想。第三是控制權與可攜性，免費域名若因政策調整而變動，使用者能掌握的空間相對有限。

實務上，兩者並非互斥。許多開發者會以免費域名進行前期測試與原型驗證，待專案成熟後再轉往付費域名；對於教學用途或內部工具，免費後綴則具備明顯的成本優勢。專案的價值不在於取代付費註冊商，而在於把「先有一個自己的網址」這件事的門檻降到接近於零。

常見問題有哪些？

常見疑問集中在域名數量、DNS 設定方式與費用；每個帳號預設限一個域名，解析須交由外部權威名稱伺服器，專案本身完全免費並以 AGPL-3.0 授權。

FreeDomain 是免費的嗎？

是。域名註冊不收費用，專案以 AGPL-3.0 授權開源，使用者只需自備外部 DNS 供應商。

每個帳號可以註冊幾個域名？

預設為一個，這項政策是因應域名濫用而調整；若需要更多名稱，可在已取得的域名之下建立子域名。

可以在 FreeDomain 後台直接新增 DNS 記錄嗎？

不行。FreeDomain 只負責域名核發與委派，A、CNAME、MX 等紀錄都須在外部權威名稱伺服器供應商設定。

FreeDomain 支援哪些域名後綴？

目前提供 .DPDNS.ORG、.US.KG、.QZZ.IO、.XX.KG 與 .QD.JE 五種，官方表示未來會陸續增加。

免費域名適合商業網站嗎？

用於測試、教學或內部工具相當合適；若需建立品牌信任，建議待專案成熟後改用 .com 等付費主流後綴。

總結：FreeDomain 適合哪些使用者？

FreeDomain 適合學生、個人開發者與教學用途，能以零成本取得域名並搭配完整教材學習 DNS；需要品牌級後綴與技術支援的商業網站仍應選擇付費註冊商。

FreeDomain 的價值在於把取得網址的門檻降到接近於零，並以完整教材補上新手最缺乏的 DNS 知識。專案以 AGPL-3.0 授權開源，在 GitHub 累積 202,637 顆星標與 4,445 次複製，平台已發出逾五十萬個域名，後綴涵蓋 .US.KG、.QZZ.IO 等五種。需要留意的是，它不提供 DNS 記錄編輯，使用者必須自行指定外部權威名稱伺服器；對於願意多花一步設定的學生、個人開發者與教學者，這套免費方案提供了低成本的起步路徑。
