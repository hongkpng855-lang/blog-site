AI 教學總覽

不必看官方英文文件，這裡用繁體中文一步一步教你安裝、教你設定、教你避開我踩過的坑。每篇都是我親手跟著做一次才寫。

從何處開始學 AI？

如果你完全未接觸過，建議的順序是：先學寫 Prompt，掌握基本溝通方式；再學用 CLI 工具（例如 Claude Code），讓 AI 直接進入你的專案；最後才學 API 與自動化，把重複工序交給程式。跳步去學最複雜的部分，通常會事倍功半。

常見問題

完全不懂寫程式可以學嗎？

可以。Prompt 與日常工具的使用不需要程式基礎；但若要做到自動化、接 API，就需要基本的命令行操作與簡單程式概念。教學內會標明每篇的前置要求。

要用多少錢？

入門階段大部分工具都有免費額度，足以應付學習。要付費通常是用量大或需要更強模型的時候。教學內會標示實測當時的價錢與免費額度上限。

教學會跟住官方更新嗎？

會。每篇教學都標明實測日期與版本，若官方介面有重大改動，會更新文章並註明修訂時間。
