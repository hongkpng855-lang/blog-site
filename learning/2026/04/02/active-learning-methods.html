主動學習法-讓學習效果翻倍的實用技巧

Eric Chan

IT 顧問・實測主義者

2026年04月02日 19:36 • 閱讀時間 2 分鐘

為什麼你讀了很多卻記不住？

很多人有過這樣的經驗：花了時間讀書、看文章、上課，覺得自己學了很多，但過幾天就忘得差不多了。

這不是記憶力不好，而是學習方法有問題。

大部分人的學習是「被動的」：看過去、聽過去，就覺得自己學會了。但被動學習的留存率非常低。

研究顯示，不同的學習方式，兩週後的記憶保留率：

學習方式 保留率
聽講 5%
閱讀 10%
聽與看 20%
示範 30%
討論 50%
實做 75%
教別人 90%

「教別人」的保留率是「聽講」的18倍。這就是主動學習的力量。

什麼是主動學習？

主動學習的核心是：讓大腦主動參與學習過程，而不是被動接收資訊。

被動學習的人：

  • 看書時只是眼睛掃過文字
  • 上課時只是聽老師講
  • 畫重點時只是把字塗顏色

主動學習的人：

  • 看書時不斷問問題
  • 上課時主動思考、做筆記
  • 用自己的話解釋內容

主動學習的5個核心技巧

技巧一：預習與提問

在開始學習之前，先做準備。

預習步驟：

  1. 看標題和目錄，了解整體架構
  2. 問自己：我想學什麼？我有什麼問題？
  3. 帶著問題開始閱讀或聽講

為什麼有效？ 預習讓大腦建立「知識框架」，後續學習的內容有地方可以「掛上去」，更容易理解和記憶。

技巧二：用自己的話解釋

讀完一段內容後，用自己的話說出來或寫下來。

實踐方法：

  • 蓋上書本，用自己的話解釋剛讀的內容
  • 假裝要教一個不懂這個主題的人
  • 如果解釋不出來，代表還沒真正理解

常見錯誤： 只是把書上的話抄一遍。真正的理解是可以用自己的話說出來。

技巧三：間隔重複

不要一次學很久然後就不管，而是分散時間，多次複習。

間隔重複的節奏：

  • 第一次複習：學習後24小時內
  • 第二次複習：3天後
  • 第三次複習：1週後
  • 第四次複習：1個月後

為什麼有效？ 大腦會認為「多次出現」的資訊是重要的，因此更容易存入長期記憶。

技巧四：主動提取

很多人複習的方式是「重讀」，但更有效的方式是「主動提取」。

主動提取練習：

  • 蓋上書本，盡可能回憶內容
  • 做練習題或測驗
  • 用心智圖畫出學過的內容
  • 嘗試不看筆記回答問題

為什麼比重讀有效？ 主動提取是「測試」大腦是否真的記住，過程中會強化記憶路徑。重讀只是再次輸入，大腦不需要努力提取。

技巧五：教別人

學習的最好方式是「教」。

教學的好處：

  • 必須真正理解才能解釋清楚
  • 教的過程會發現自己的盲點
  • 教別人是最高層次的記憶強化

實踐方式：

  • 找朋友分享你學到的內容
  • 寫文章或製作簡報教別人
  • 錄影片解釋概念
  • 參加讀書會分享

沒有人可以教怎麼辦？假裝在教一個想像中的學生。

不同學習場景的主動學習應用

場景一：閱讀書籍

被動做法：從頭看到尾，畫線就覺得學會了。

主動做法：

  1. 先看目錄，預想內容架構
  2. 帶著問題開始閱讀
  3. 每章結束後用自己的話寫摘要
  4. 讀完整本書後寫書評或心智圖

場景二：上課或聽演講

被動做法：坐著聽，偶爾拍照。

主動做法：

  1. 上課前先預習相關內容
  2. 聽講時主動思考：這和我已知的有什麼關聯？
  3. 做筆記時用自己的話寫，不是抄投影片
  4. 課後和同學討論或教別人

場景三：線上課程

被動做法：影片放著看，偶爾暫停。

主動做法：

  1. 每個單元結束後暫停，用自己的話說一次
  2. 做課程附帶的練習題
  3. 把學到的應用在實際專案
  4. 寫學習筆記或分享

場景四：學習新技能

被動做法：看教學影片，覺得懂了。

主動做法：

  1. 看完示範後關掉影片，自己嘗試
  2. 遇到問題再回去看
  3. 做一個實際專案應用所學
  4. 教別人或分享過程

克服主動學習的阻力

主動學習比較累，因為大腦需要真正運作。這就是為什麼很多人選擇被動學習——比較輕鬆。

如何克服阻力？

  1. 降低門檻：從小範圍開始，例如每讀一章就用自己的話說一次
  2. 建立習慣：把主動學習變成標準流程，每次學習都這樣做
  3. 追蹤效果：感受主動學習帶來的進步，會增加動力
  4. 接受不完美：一開始會覺得困難，這是正常的

主動學習的常見問題

Q1：這樣學不是很慢嗎？

表面上看起來比較慢，但實際上更有效率。

  • 被動學習：快但記不住，需要重複很多次
  • 主動學習：慢但真正學會，整體時間更省

Q2：所有內容都要主動學習嗎？

不需要。有些內容只需要概略了解，可以快速瀏覽。重點內容才需要深度主動學習。

Q3：沒時間怎麼辦？

主動學習不是花更多時間，而是用更好的方式使用時間。同樣的時間，主動學習效果更好。

Q4：如何判斷自己是否學會？

試著用自己的話解釋，或教別人。如果說不出來，就是還沒真正學會。

結語

學習的目的不是「看過」或「讀完」，而是「學會」和「記住」。

主動學習需要更多心力，但效果是被動學習的數倍。

從今天開始，試著：

  • 閱讀時帶著問題
  • 讀完後用自己的話解釋
  • 適時複習並主動提取
  • 把學到的教給別人

你會發現，學習變得更有深度，記憶也更加持久。
